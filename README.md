# LinkedIn-Ausgang von Baubotters

Dieser Zweig enthält nur Beiträge, die auf LinkedIn erscheinen sollen. Der CEO-Agent legt sie an, der LinkedIn-Agent liest sie.

- `offen.md`: Liste aller Beiträge mit Datum, Ordner, LinkedIn-Seite und Status.
- Je Beitrag ein Ordner `JJJJ-MM-TT-name/` mit `text.md` (der Beitragstext, genau so zu posten) und `video.mp4` oder Bildern.

Status: `offen` heißt noch nicht auf LinkedIn. `gepostet` trägt der CEO-Agent ein, sobald Daniel den Link gemeldet hat.

Adressen zum Lesen ohne Anmeldung:
- Liste: https://raw.githubusercontent.com/danninobs-coder/baubotters-medien/linkedin/offen.md
- Datei eines Beitrags: https://raw.githubusercontent.com/danninobs-coder/baubotters-medien/linkedin/<Ordner>/<Datei>
