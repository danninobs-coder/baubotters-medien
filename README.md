# Baubotters Medien

Öffentliche Ablage für Bilder und Videos der Instagram-Beiträge von Baubotters.
Instagram holt die Medien über die öffentlichen Adressen dieses Repos ab.

Regeln:
- Nur Medien, die für einen Beitrag freigegeben sind.
- Nur selbst erstellte Grafiken, keine Kundendaten, keine Fotos von Personen ohne Einwilligung.
- Ordner je Beitrag: `instagram/JJJJ-MM-thema/`.
- Nichts nachträglich ändern: Die Prüfsumme eines Beitrags hängt an den Adressen.
